## II. Observations on New Features (V2.16)

The new version introduces several mechanics that significantly enhance the gameplay experience, particularly around resource management and advisor interaction.

### 1. The Advisor System

The advisor is now a much more dynamic and challenging element. The system successfully creates a feeling of working under a demanding supervisor.

| Advisor Feedback | Frequency | Impact on Gameplay |
| :--- | :--- | :--- |
| **Negative/Inconclusive** | Very High | Forced repeated actions ("Develop Findings") and delayed progress. |
| **Summer Internship Penalty** | Consistent (-5 Advisor) | The advisor consistently penalized the player for taking the internship, but the penalty was too small to deter the action. |
| **Positive Feedback** | Low | Occasional morale boosts for "Solid discovery" but rare overall. |

**Observation:** The advisor's constant impatience and critical feedback are effective for flavor but contribute significantly to the slow pace of the game. The penalty for the Summer Internship is negligible compared to the massive morale and network boost it provides, making the choice a strategic necessity rather than a meaningful trade-off.

### 2. New Events (Scooped, Equipment Failure)

These events add crucial variability and challenge to the mid-to-late game.

*   **"Scooped" Event (Month 75):** This is an excellent addition that simulates a real-world academic risk. The penalty (-1 idea, -5 morale) is appropriate.
*   **"Equipment Failure" Event (Month 89):** This event blocked the "Validate Discovery" action for three months until the equipment was fixed (`Month 92`). This is a realistic and impactful time sink that forces the player to pivot to other actions (like submitting the paper or taking a break).

### 3. Summer Internship Action

The Summer Internship is arguably the most powerful action in the game.

*   **Benefit:** +25 Peer Network, +15 Morale (for 3 months).
*   **Cost:** 3 months of research time, -5 Advisor Happiness.

**Observation:** The massive morale and network gain from the internship makes it a mandatory action, especially when morale is low. The time cost is offset by the morale boost, which prevents the player from needing to take multiple "Take a Break" actions. The advisor penalty is too minor to be a deterrent.

## III. Suggestions for Improvement

Based on the V2.16 playthrough, here are suggestions to improve game balance, depth, and player experience.

### 1. Game Balance and Pacing

The 95-month duration is too long. The core research loop needs to be accelerated to make the game feel less like a grind.

| Suggestion | Rationale |
| :--- | :--- |
| **Reduce "Develop Findings" Steps** | The transition from "Work on Idea" to "Key Discovery" is too slow. Reduce the number of required "Develop Findings" actions from 3-4 to 2-3. |
| **Introduce "High-Risk/High-Reward" Actions** | Add an action like "High-Throughput Experiment" that costs more morale/credits but has a chance to instantly grant a Key Discovery or multiple Figures. |
| **Increase "Read Papers" Utility** | The "Read Papers" action should have a chance to grant a small morale boost or a temporary buff (e.g., "Focused Research: Next 'Develop Findings' is 50% faster"). |

### 2. Advisor System Refinement

The advisor penalty for the Summer Internship needs to be more impactful to create a genuine strategic choice.

| Suggestion | Rationale |
| :--- | :--- |
| **Increase Internship Penalty** | Change the penalty from a small, one-time -5 Advisor Happiness to a temporary, more severe effect, such as **-5 Alignment** or a **"Slow Response"** status effect for the next 3 months (advisor takes 2 months to respond to a pitch/draft). |
| **Introduce "Advisor Alignment" Benefits** | If Advisor Alignment is high, grant a bonus to the "Journal Paper" action (e.g., "Advisor's strong recommendation: -1 month review time"). |
| **Make "Pitch Session" More Informative** | The pitch session should provide a clearer, more actionable hint about the next required action (e.g., "Focus on controls" or "Need a bolder claim") rather than just a general mood update. |

### 3. New Event Mitigation

The new negative events are good, but the player should have a way to mitigate them through prior action.

| Suggestion | Rationale |
| :--- | :--- |
| **"Pre-register Idea" Action** | Add a new action that costs a small amount of network and morale but makes the "Scooped" event impossible for that idea. This simulates registering a pre-print or patent. |
| **"Equipment Maintenance" Action** | Add a low-cost action that temporarily prevents the "Equipment Failure" event. This rewards proactive resource management. |

### 4. Publication Pipeline

The high rejection rate (3/3 papers rejected/major revision) is realistic but can be frustrating.

| Suggestion | Rationale |
| :--- | :--- |
| **Network/Alignment Impact on Review** | Make the Peer Network and Advisor Alignment stats influence the probability of rejection/revision. A high Network/Alignment should slightly increase the chance of a smooth acceptance. |
| **Conference Paper Utility** | Conference papers currently only grant network. They should also grant a small, permanent **+1 Alignment** bonus, simulating the benefit of presenting work and getting feedback before a journal submission. |

These changes would help to balance the high difficulty, reward strategic planning, and make the overall 3-paper journey feel more varied and engaging.
